# Learning Reflection

## Introduction

This project was developed as part of the AI-Augmented Workflow course.

The main goal of the project was to understand the basic concept of an
AI Agent and develop a simple working AI Agent using Python, Ollama, and
the Llama 3.2 language model.

This project also helped me understand how software projects can be
organized, documented, tested, and maintained using Git and GitHub.

---

## What I Learned

During this project, I learned the basic concepts of AI Agents and how
a programming application can communicate with a language model.

I learned that an AI Agent can receive an input, process the request
using an AI model, and provide a response to the user.

I also learned how Python can be used to create an AI-based application.

---

## Learning Python for AI

Python was used as the main programming language for this project.

I learned how to:

- Create a Python program.
- Install Python packages using pip.
- Create and use a virtual environment.
- Run Python programs from the terminal.
- Use a Python library to communicate with Ollama.

Python was useful because its syntax is simple and it has many libraries
for Artificial Intelligence and Machine Learning.

---

## Learning Ollama and Llama 3.2

Instead of using a cloud-based OpenAI API, I decided to use Ollama.

Ollama allows a language model to run locally on the computer.

I installed Ollama and downloaded the Llama 3.2 model. I then connected
the model to my Python program using the Ollama Python package.

This helped me understand the relationship between an application and
a language model.

The basic workflow was:

```text
User Input
    ↓
Python AI Agent
    ↓
Ollama
    ↓
Llama 3.2
    ↓
AI Response
